# Super-ASCII-Maker
An ASCII game engine, currently being designed in python.

### What is this?
This is a text based game engine, as a base for any game I want to make, but I am going to put the engine here if anyone else wants to use it. This will be my first project I post on github, so I apologise for any bugs/weirdnes that happen in early versions.
### Do I know about X thing that already does this?
Probably not, but the goal of this project is for me to learn python better, so even if there are any other ASCII game engines out there, I still will make this one.
